# Employee Management System

This is a full-stack Employee Management System built with:
- **Backend:** ASP.NET Core Web API
- **Frontend:** Angular

## 📁 Project Structure


---

## ⚙️ Backend (.NET Core API)

### Prerequisites

- [.NET SDK 7.0+](https://dotnet.microsoft.com/en-us/download)
- [SQL Server](https://www.microsoft.com/en-us/sql-server/)
- (Optional) Visual Studio or VS Code

### Setup & Run

1. **Navigate to the backend folder**:

```bash
cd EmployeeApi/EmployeeApi

2.Restore dependencies:

dotnet restore

3.Run the API:

dotnet run

The API should start on:

https://localhost:7148


Setup & Run
1. **Navigate to the frontend folder**:

```bash
cd employee-management

2.Install dependencies:

npm install


3.Run the Angular app:
ng serve

The app should be available at:

https://localhost:7148/api/Employee
Make sure the backend is running before using the Angular app.
